# Инвентаризация и обновление Linux

Реализация для Astra Linux, Debian и Ubuntu находится в **[fleet/](fleet/README.md)**.
Он запускается с рабочей станции: список IP/DNS → проверка SSH или выбор действия → локальные отчёты.

Сценарии в `ansible/` и `.github/workflows/os-update.yml`  не используются
