# Инвентаризация и обновление Linux

Новый Ansible-проект для Astra Linux, Debian и Ubuntu находится в **[fleet/](fleet/README.md)**.
Он запускается с рабочей станции: список IP/DNS → проверка SSH или выбор действия → локальные отчёты.

Сценарии в `ansible/` и `.github/workflows/os-update.yml` относятся к прежней реализации
и не используются новым проектом. Их существующее расписание этим изменением не меняется.
