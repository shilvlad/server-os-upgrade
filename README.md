# Инвентаризация и обновление Linux

Ansible-инструмент для Astra Linux, Debian и Ubuntu. Запускается с рабочей станции,
подключается по SSH к списку IP/DNS и помогает принять решение об обновлении.

- Проверка SSH-доступа ко всем серверам.
- Сбор установленных пакетов и доступного ПО.
- Понятный план: версии до/после, ядро, перезагрузка и предупреждения.
- Выбор серверов и подтверждение установки после просмотра плана.
- Локальные отчёты и настраиваемые проверки приложений.

**[Установка, примеры и ограничения — в fleet/README.md](fleet/README.md).**

GitHub Actions выполняет тесты на временных runner-ах. Обновления серверов запускаются
пользователем через `fleet/run.py`; SSH-ключи и рабочие inventory в GitHub не нужны.
Старая реализация автоматических обновлений удалена из рабочей версии; она доступна
в истории Git. Откат пакетов, миграция выпуска ОС и проверка CVE не выполняются автоматически.
